# Ludoman project

The canonical shared factory has moved to https://github.com/Freebielife/TON-Observatory-Template.
For every NEW token observatory, start from that independent repository and its
AGENTS.md. Do not use Ludoman's live source as the factory. The local factory
scripts remain for historical compatibility and do not synchronize automatically.

Ludoman may be customized independently, including its project-only DEV badge.
Never propagate those settings into the shared template or other token projects.
Do not change KITO without a separate request.

For every new observatory, follow docs/BRANDING_STANDARD.md before generation:

- Hero logo: the token's own metadata image, or its project website. Record the source and embed the downloaded logo.
- Section flag: explicitly confirm its mapping in the owner's TONecoFlags catalogue. If the needed asset is missing, ask the user for the correct emoji/file. Never silently reuse the hero logo as a flag or choose a different project's flag.
- Project channel: require the actual Telegram channel, shown in the hero and useful links. If not found in verified project sources, ask the user; never invent a username.

Keep the standalone page self-contained. Validate mobile layout, links, buttons and overflow. Changes to the factory do not authorize migrating existing observatories or touching KITO.
